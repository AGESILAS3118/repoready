# Security Policy for RepoReady

## Reporting Vulnerabilities / Signaler une vulnérabilité

RepoReady is a 100% client-side tool with zero server backend and zero external runtime dependencies. However, we take security seriously—especially concerning input sanitization, YAML/Markdown escaping, and Content Security Policy (CSP).

### English
Please **do not** open public GitHub issues for security vulnerabilities or potential script injection vectors.

Instead, please report vulnerabilities privately using GitHub's **Private Vulnerability Reporting**:
1. Go to the [Security Advisory tab](https://github.com/AGESILAS3118/repoready/security/advisories/new).
2. Click **Report a vulnerability**.
3. Provide details, steps to reproduce, and any recommended fix.

We will acknowledge your report within 48 hours and release a patch as quickly as possible.

---

### Français
Merci de **ne pas** ouvrir d'issue publique sur GitHub pour signaler une faille de sécurité ou un vecteur potentiel d'injection.

Veuillez utiliser le dispositif de signalement privé **GitHub Private Vulnerability Reporting** :
1. Rendez-vous sur l'onglet [Security Advisories](https://github.com/AGESILAS3118/repoready/security/advisories/new).
2. Cliquez sur **Report a vulnerability** (Signaler une vulnérabilité).
3. Décrivez la vulnérabilité, les étapes pour la reproduire et les pistes de correction.

Nous accuserons réception de votre rapport sous 48 heures et publierons un correctif dans les plus brefs délais.
