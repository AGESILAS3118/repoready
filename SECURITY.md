# Security Policy for RepoReady

## Reporting Vulnerabilities

RepoReady is a 100% client-side tool with zero server backend and zero external runtime dependencies. However, we take security seriously—especially concerning input sanitization, YAML/Markdown escaping, and Content Security Policy (CSP).

If you discover a security vulnerability or potential script injection vector, please report it privately:

👉 **Email:** security@repoready.org

We will acknowledge your report within 48 hours and release a patch as quickly as possible.
